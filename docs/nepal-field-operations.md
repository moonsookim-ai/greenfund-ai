# 네팔상황실: 한국 구조대원을 위한 현장 브리핑

2026-09-05 · GREEN PROOF, 환경재단이 운영하는 AI환경연구소. GPT-6 Astra로 공개 근거 검토, 실행안 설계와 구현을 수행했다.

## 목적과 범위

`/nepal/`은 한국 구조대원과 파견팀의 지휘·연락·의료·물류 담당자가 읽는 현장 정보 페이지다. 라수와·누와코트·다딩별 피해·접근 제약, 사고 당시 위험, 병원명 대조, 현지·한국 측 연락 창구와 파견·교대 참고사항을 제공한다. 구조 요청을 작성하는 흐름을 주 화면에서 제거했다. 지역 정보는 공개 자료의 요약이고 실행상 의미는 GREEN PROOF의 해석이며, 한국팀의 실제 파견·임무 배정·승인된 작전·진행 실적이 아니다.

구조·의료 우선순위를 계산하지 않는다. 식수·위생 모델 A는 별도 지원 검토 기능으로 유지한다. 위성 사진은 8월의 역사적 관측이며 현재 통행 가능 경로나 안전한 대피소를 판정하지 않는다. 한국팀의 배치, 국제 조정소 설치 위치, 병상·헬기·차량 접근, 미수색 구역은 미확인으로 남긴다.

라수와의 접근 제약, 누와코트의 주요 피해와 Devighat 관찰, 다딩의 보건시설·접근 제약은 기존 스냅샷의 IFRC·HEOC·World Vision 자료를 인용했다. 나머지 영향 지구의 자료 부족은 별도 확인 과제이며 낮은 구조 우선순위를 뜻하지 않는다.

## 화면 구성과 보조 도구의 개인정보 흐름

- `/nepal/`: 한국 구조대원용 정보 열람. `#evidence`는 지역별 대원 브리핑, 기존 가구 자료 구간은 `#aid-evidence`로 이동했다. 신고 양식은 주 화면에 없다.
- `/nepal/field/`: 약 97 KB의 한국어 독립 HTML 브리핑. 입력 없이 읽고 지역을 선택하거나 전체 인쇄·PDF 저장할 수 있다. 외부 글꼴·사진·모듈·데이터 요청이 없다. 미리 다운로드하면 오프라인에서도 정보 열람이 가능하다.
- `/nepal/handoff/`: 기존 영문 요청·인계 양식을 별도 보조 페이지로 유지한다. 아래 입력·출력 설명은 이 보조 도구에만 적용된다.
- 자유 입력 문장은 번역하지 않는다. 자동 번역으로 현장명·의료 상태를 변형하지 않으며, 전달 상대가 이해할 언어로 입력하도록 안내한다.
- 서버 전송·백그라운드 통신·브라우저 영구 저장소 없음. 입력은 화면 메모리만 사용. 재로딩 전 명시적으로 다운로드해야 남는다.
- 좌표는 버튼을 눌렀을 때만 기기 권한을 요청한다. 항상 제보자 위치로 채우고 정확도·취득 시각을 남긴다. 구조 대상 위치로 추정하지 않는다. 수동 좌표 변경 시 기존 기기 출처·위치 유형을 초기화한다.
- 지도는 좌표 확인용 OpenStreetMap 외부 링크이다. 클릭할 때 좌표가 전달됨을 안내하며 경로 추천을 하지 않는다.
- 초안 복사·파일 저장·인쇄만 제공한다. 전화·메시지 전달은 사용자가 수행한다. 파일에는 위치·연락처가 포함될 수 있어 필요한 대응기관에만 공유하도록 안내한다.
- 메일 난독화가 외부 복호화 스크립트를 삽입하지 않도록 현장 HTML에 `email_off`와 해당 경로에 `no-transform`을 적용한다. 도메인 전체 보안 설정을 변경하지 않는다.

## 입력·상태 해석

`field-model.mjs` 순수 함수가 기록을 만들고 `field.mjs`가 화면을 연결한다.

빈 인원·좌표·시각은 `null/UNKNOWN`으로 남기며 0이나 현재 시각으로 대체하지 않는다. 인원은 비음수 정수, 좌표는 WGS84 십진수 위도·경도 쌍으로 검증한다. 네팔 주변의 넓은 범위를 벗어나면 오기 가능성을 표시한다. 이 범위는 행정 경계나 피해 영역이 아니다.

시각은 장치 시간대와 관계없이 네팔 UTC+05:45로 해석하고 UTC도 JSON에 보존한다. 관찰·연락·확인 시각은 미래 입력을 거부한다(장치 시계 오차 1분 허용). 다음 연락 예정 시각은 미래일 수 있다. 현지 연락처가 알려준 시각을 입력하는 필드는 자동 완성하지 않는다.

모든 결과의 전송 상태는 `NOT_SENT_BY_THIS_TOOL`. 사용자 기록 번호는 공식 접수번호와 구분한다. `acknowledged`에는 기관·연락 시각·접수번호 또는 확인 내용이 있어야 하지만 여전히 사용자 기록일 뿐이다. 실제 출동으로 전환하는 상태는 없다.

기상·도로·수용시설·통신 확인은 확인 내용과 시각을 요구한다. 네 항목이 모두 채워져도 `LOCAL_AUTHORITY_DECISION_REQUIRED`를 유지한다. 통제·수용 불가·문제 보고는 별도 표시하며 확인표를 통행 허가로 쓰지 않는다. 입력이 변경되면 이전 초안과 다운로드 동작을 무효화해 오래된 내용을 전달하지 않도록 한다. 초기화한 뒤 도착한 비동기 위치 응답도 폐기한다.

## 빌드와 검증

```sh
python tools/build_site_headers.py
python tools/build_nepal_field.py
python tools/build_nepal_briefing.py
python tools/check_web.py
node --test tests/nepal-model.test.mjs tests/nepal-field.test.mjs tests/nepal-briefing.test.mjs
```

`build_nepal_briefing.py`는 동일한 출처 자료로 주 화면과 한국어 오프라인 브리핑을 생성한다. `build_nepal_field.py`는 영문 보조 양식만 생성한다. 생성 HTML도 Git에 커밋한다. 지역 공개 점수 모델은 변경하지 않았다.

상단 대메뉴는 `tools/site_header.py`와 `greenproof/web/site-header.css`를 공통으로 사용한다. 온라인 3개 페이지는 `build_site_headers.py`로 갱신하고, 오프라인 문서 빌더는 같은 헤더와 CSS를 내장한다. 현재 메뉴의 `aria-current`만 달라진다. 식재지·언어 선택은 본문 도구 영역에 유지하며 상단 메뉴명은 동일한 한국어 표기를 사용한다.

검증 범위: 날짜·UTC 변환, 미확인과 0, 잘못된 좌표·인원, 미래 시각, 기관 확인 요건, 확인표의 비승인 상태, 초안 전송 상태, 문자열 처리, 연락처 출처, HTML/JS 구문, 로컬 자원·앵커, 독립 HTML의 무의존성. 실제 전화, GPS 하드웨어, 클립보드/인쇄 대화상자, 현장 통신망 가용성을 검증한 것은 아니다.


## 원문 기반 한국어 해설과 텍사스 서문 · 2026-09-06

`data/source-analyses.json`이 18개 주제의 한국어 요약·해석·범위와 서문의 정본이다. `tools/nepal_sources.py`와 브리핑 빌더가 같은 내용을 주 페이지·오프라인 문서에 생성한다. 기존 브리핑·구호 모델 출처 링크는 페이지 안의 해설을 열며, 해외 원문은 해설 안의 보조 대조 링크로 남긴다. 책 전체의 공식 번역으로 표시하지 않는다. 원문 PDF를 사이트에 복제하지 않고 확인한 내용을 재서술한다.

팔란티어 사례는 기업 공식 계정이 공개한 Texas DPS Captain John Miller의 AIPCon 8 발표 전사문을 근거로 한다. 요청 다음 날 기술진 합류, 48시간 이내 Gaia·Foundry 환경 구축, 참여기관 확대는 발표자의 설명으로 명시한다. 2025년 7월 4일 홍수의 지역·다기관 대응 배경은 TDEM 발표로 대조했다. 독립적인 성과 평가나 구조 인원·시간 절감·인명 구조 효과를 추정하지 않는다. GREEN PROOF의 팔란티어 협업·플랫폼 도입·현장 실시간 연동을 주장하지 않는다.

HEOC PDF 7쪽 원본에서 보건시설의 완전 파손·부분 파손·접근 장애 구분을 확인했다. 영문·네팔어판의 증상별 수치 차이는 해설에 적고 수치 합산을 제외했다. INSARAG 2020 정책 지침 23–27쪽, 운영 지침 22–24·37–40쪽, 현장 지침 8–11·24–29·31–39쪽의 관련 내용을 읽어 국제팀 접수·조정·정보 인계·의료·물류·안전의 한국어 해설을 구성했다. PDF 쪽수와 문서의 인쇄 쪽수 차이에 주의한다.

추가 검증: 모든 근거의 내부 해설 연결, 주·오프라인 페이지 내용 일치, 심층 링크로 접힌/검색에서 숨긴 해설 열기, 인쇄 전 전체 내용 표시와 인쇄 후 검색·펼침 상태 복원. 테스트는 DOM 대역을 이용한 이벤트 로직 검증이며 실제 브라우저 인쇄 대화상자 검증이 아니다.
